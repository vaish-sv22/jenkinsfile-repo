# Jenkinsfile Repository

This repository contains sample **Jenkins Pipelines**, **Shell Scripts**, and **Jenkins Installation Scripts** that demonstrate Continuous Integration (CI) and Continuous Deployment (CD) concepts using Jenkins.

---

## Contents

### 1. Jenkins Declarative Pipeline

A basic Jenkins pipeline consisting of multiple stages:

- Build
- Test
- Deploy

Example stages:

- Build application
- Execute test stage
- Deploy application

---

### 2. Terraform Jenkins Pipeline

A Jenkins pipeline for Infrastructure as Code (IaC) using Terraform.

Pipeline stages include:

- Checkout source code
- Terraform Init
- Terraform Plan
- Terraform Apply

Features:

- AWS Credentials
- Environment Variables
- Build Parameters
- Terraform Automation

---

### 3. Shell Script

Simple Bash script demonstrating:

- Script execution
- Console output
- Basic Linux scripting

---

### 4. Jenkins Installation Script

Automates Jenkins installation on Amazon Linux.

The script performs:

- System update
- Install Java
- Configure Jenkins repository
- Install Jenkins
- Start Jenkins service
- Display initial admin password
